
AI 여행 서비스 포트폴리오 웹어플리케이션 만들기
1. 회원가입 및 로그인
사용자는 이메일 또는 소셜 로그인(Google, Kakao 등)을 통해 회원가입 및 로그인을 진행할 수 있다. 회원가입 후 개인별 여행 정보와 추천 경로를 저장 및 관리할 수 있으며, 이전에 생성한 여행 일정도 언제든지 다시 확인할 수 있다.
2. 메인 메뉴
로그인 후 사용자는 다음과 같은 기능을 이용할 수 있다.
(1) 여행지 검색부
사용자가 여행하고 싶은 국가 또는 도시를 검색하면 해당 지역의 대표 관광지, 맛집, 쇼핑 장소 등을 확인할 수 있다.
(2) AI 여행 경로 추천
여행 기간, 예산, 여행 스타일 등을 입력하면 AI가 최적의 여행 일정을 자동으로 생성한다.
(3) 추천 여행 경로
다른 사용자들이 실제로 다녀온 여행 경로를 확인할 수 있으며, 인기 있는 여행 코스와 평점을 참고하여 자신의 여행 일정에 활용할 수 있다.
3. 여행 정보 입력
사용자는 AI에게 여행에 필요한 다양한 정보를 입력한다.
여행 국가 및 도시 여행 기간 (예: 2박 3일) 여행 인원 예산 숙소 위치 선호하는 여행 스타일 관광 중심 맛집 중심 쇼핑 중심 힐링 여행 가족 여행 커플 여행 혼자 여행 반드시 방문하고 싶은 장소(선택) 4. AI 여행 일정 생성
입력된 정보를 바탕으로 AI가 여행 일정을 자동으로 생성한다.
AI는 다음 요소를 종합적으로 고려하여 경로를 추천한다.
이동 거리 최소화 교통수단 관광지 운영시간 식사 시간 여행자의 선호도 일정의 효율성
예를 들어,
"일본 도쿄 3박 4일, 예산 100만 원, 쇼핑과 맛집 위주"
를 입력하면 AI는 날짜별 이동 경로와 추천 관광지를 포함한 여행 일정을 자동으로 생성한다.
5. 일정 수정 기능
AI가 만든 일정을 사용자가 수정 가능
예)
아키하바라 삭제
↓
AI가 다시 최적의 경로 계산
이게 AI를 사용했다는 느낌이 가장 강하다.
6. 즐겨찾기
마음에 드는 여행지를 저장
7. 여행 일정 저장
생성한 AI 일정을
저장, 수정 ,삭제 가능하도록 구현
8. 커뮤니티(추천 경로)
남들이 다녀온 여행 일정(조회수, 좋아요 가능)
클릭하면 일정 확인
개인적으로 하나 더 추가하고 싶은 기능 (차별화 포인트)
AI 채팅 기능을 넣는 거야.
예를 들어 사용자가
"둘째 날은 비가 올 것 같아."
라고 입력하면
AI가
"실외 관광 대신 쇼핑몰과 실내 관광 위주로 변경하겠습니다."
처럼 일정을 다시 생성해 주는 기능이야.
이 기능 하나만 있어도 단순한 "여행 일정 생성기"가 아니라 AI와 대화하며 여행 계획을 완성하는 서비스가 되어 포트폴리오의 완성도가 크게 올라간다.
1. AI에게 날씨를 알려주세요 하는 채팅창은 보낼 때 스크롤이 아래에 고정되었으면 좋겠는게, 위로 가 있어서 아래 채팅을 자꾸 내려야돼.
2. 계속 비가 오는 날 기준으로 해서 실내로 변경하고 있어. 둘째날은 눈이와 하는데도 실내라고 인식하고 있을 뿐더러 이어서, 실외로 해줘 라고 붙여도 날짜를 인식하지 못하고 있어
3. 여행지 검색에서 이 여행지로 일정만들기 선택할 때, 하단에 나와있는 걸 즐겨찾기 하고 해당 여행지로 일정을 세웠을 때 즐겨찾기 했던 여행지도 일정 목록에 나왔으면 좋겠어 그러니까
4. 커뮤니티에서 다른 사람이 짠 일정을 보고 나서 한번씩 볼때마다 조회수가 +2가 되고 있어
5. 일정을 세우고 나서 해당 위치가 지도에 표시할 수 있도록 구글지도에 바로 연결했으면 좋겠어
6. 백엔드로 넘어가줘
